## Steps
1. Choose a specific question engineers search for; check the SERP using
   the browser and note what existing articles miss.
2. Outline: problem, key concepts, step-by-step approach, checklist,
   common mistakes, where GRAVLOC helps (one honest paragraph, no hard sell).
3. Be technically accurate. Cite public standards and sources; mark anything
   uncertain as [VERIFY]. Never invent numbers or standards details.
4. Add title, meta description, headings, internal links, a downloadable
   checklist idea.
5. Send to the CTO or space advisor for technical review before approval.
6. Never copy from other sites; paraphrase and cite.
