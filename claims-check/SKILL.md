---
name: claims-check
description: Check any marketing copy for unsupported, risky or non-compliant claims before approval. Use on every draft before it goes to the founder.
---
## Steps
1. Highlight every factual claim (numbers, rankings, comparisons,
   customers, partners, features, timelines, compliance).
2. Mark each: proven / planned / unproven / risky. Compare with the
   "Claims status" section in MEMORY.md.
3. Remove or reword anything unproven. Features not built yet must say
   "planned".
4. Flag: unapproved names/logos, competitor disparagement, export-controlled
   or NDA details, legal/compliance conclusions, copyrighted material.
5. Return the copy with a short claims table and a clear recommendation.
